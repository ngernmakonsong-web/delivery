# ระบบจัดส่งสินค้า

เว็บแอปสำหรับพนักงานจัดส่ง ใช้บนมือถือ ติดตามงานส่งสินค้า วางบิล และรับเช็ค
พร้อมแผนที่ ตำแหน่ง GPS การถ่ายรูปแนบงาน ระบบผู้ใช้แยกสิทธิ์ และขั้นตรวจงาน

> ## 📖 อ่านก่อน: [คู่มือระบบการทำงาน](docs/ระบบการทำงาน.md)
>
> อธิบายครบทุกอย่าง ตั้งแต่บทบาทและสิทธิ์ วงจรชีวิตของงาน โครงสร้างข้อมูล
> ความปลอดภัย วิธีดูแลระบบ และข้อจำกัดที่ควรรู้
>
> **ถ้าคุยกับผู้ช่วย AI ในแชตใหม่ ให้ส่งลิงก์ไฟล์นั้นให้อ่านก่อน**
> จะเข้าใจระบบทั้งหมดโดยไม่ต้องเล่าใหม่

## เปิดใช้งาน

เปิดที่ **https://ngernmakonsong-web.github.io/delivery/** ด้วย Chrome หรือ Safari บนมือถือ
แล้วกดเมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอโฮม" เพื่อให้ใช้งานเหมือนแอปจริง

ครั้งแรกที่เปิด เบราว์เซอร์จะถามขออนุญาตใช้ตำแหน่ง ให้กด **อนุญาต**
ถ้าเผลอกดปฏิเสธไป ให้แตะไอคอนรูปกุญแจหรือ (i) ข้างแถบที่อยู่ แล้วเปิดสิทธิ์ตำแหน่งใหม่

## ความสามารถ

- **ร้านค้า** — เก็บข้อมูลร้านประจำไว้ครั้งเดียว ปักหมุดจากตำแหน่งที่ยืนอยู่ หรือวางพิกัดจาก Google Maps
- **งาน 3 ประเภท** — ส่งสินค้า (พร้อมรายการสินค้าและเก็บเงินปลายทาง), วางบิล (พร้อมวันนัดรับเช็ค), รับเช็ค (สลับเป็นเงินสดหรือโอนได้)
- **สถานะงาน** — มอบหมายแล้ว → กำลังเดินทาง → ถึงร้าน → ปิดงานสำเร็จ หรือ ปิดงานไม่สำเร็จ
- **ปิดงานไม่สำเร็จ** — ต้องระบุสาเหตุและเลือกวันนัดใหม่ ระบบสร้างงานรอบใหม่ให้อัตโนมัติและเก็บประวัติทุกรอบ
- **แผนที่** — หมุดงานเรียงตามลำดับ ตำแหน่งตัวเองแบบสด และปุ่มนำทางต่อไป Google Maps
- **จัดลำดับแนะนำ** — เรียงร้านจากใกล้ไปไกลให้เป็นแนวทาง คนขับปรับเองได้ตลอด
- **รูปถ่าย** — ถ่ายจากกล้องมือถือ ย่อขนาดอัตโนมัติก่อนเก็บ
- **รายงาน** — ผลงานรายคน เงินสดที่ต้องนำส่ง เช็คที่รับ ประวัติปิดงานไม่สำเร็จ ส่งออก CSV เปิดใน Excel ได้

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บอยู่ใน **เบราว์เซอร์ของเครื่องที่ใช้** (IndexedDB) ไม่ได้ส่งขึ้นเซิร์ฟเวอร์
แปลว่าแต่ละเครื่องมีข้อมูลของตัวเอง และถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย

**ควรกดสำรองข้อมูลเก็บไว้เป็นประจำ** ที่หน้าสรุป → สำรองและกู้คืนข้อมูล
ไฟล์ที่ได้เอาไปเก็บใน Google Drive ได้ และใช้ย้ายข้อมูลไปเครื่องใหม่ได้ทั้งหมดรวมรูป

ถ้าต้องการให้ออฟฟิศเห็นความเคลื่อนไหวของรถแบบสดข้ามเครื่อง ต้องต่อฐานข้อมูลกลางเพิ่ม
ซึ่งเป็นงานระยะถัดไป โครงสร้างโค้ดใน `js/db.js` ออกแบบให้เปลี่ยนไปใช้ฐานข้อมูลบนเน็ตได้
โดยไม่ต้องรื้อหน้าจอ

## ข้อจำกัดที่ควรรู้

ตำแหน่ง GPS บนเว็บจะส่งได้เฉพาะตอนเปิดแอปค้างไว้บนหน้าจอ ถ้าสลับไปแอปอื่นหรือจอดับ
ตำแหน่งจะหยุดส่ง เป็นข้อจำกัดของเบราว์เซอร์ทุกยี่ห้อ

ดังนั้นระบบจึงบันทึกพิกัดทุกครั้งที่กดเปลี่ยนสถานะงาน ทำให้ย้อนดูได้ว่าถึงร้านไหนเวลาเท่าไร
ถ้าต้องการติดตามต่อเนื่องจริง ให้ตั้งมือถือที่แท่นหน้ารถ เสียบชาร์จ แล้วเปิดสวิตช์
"กันจอดับระหว่างวิ่งงาน" ที่ไอคอนวงกลมมุมขวาบน

## โครงสร้างไฟล์

```
index.html              โครงหน้าจอ
css/app.css             สไตล์ทั้งหมด
js/db.js                ชั้นเก็บข้อมูล (IndexedDB) — เปลี่ยนเป็นฐานข้อมูลบนเน็ตได้ที่นี่
js/core.js              ค่าคงที่ ตัวช่วย สถานะแอป GPS ตัวควบคุมหน้าจอ
js/views.js             หน้าจอต่าง ๆ และรายละเอียดงาน
js/forms.js             ฟอร์มสร้าง/แก้ไข ปิดงาน รูปถ่าย สำรองข้อมูล ส่งออก CSV
js/map.js               แผนที่ (Leaflet + OpenStreetMap)
sw.js                   service worker สำหรับเปิดเร็วและติดตั้งเป็นแอป
```

แผนที่ใช้ข้อมูลจาก [OpenStreetMap](https://www.openstreetmap.org/copyright)
